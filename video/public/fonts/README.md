영상에 들어가는 글꼴

- 굵은 글씨(자막, 제목): 리틱체 REATIC (NarrowBold, Bold)
- 본문: Yeon Sung
- 손글씨: Nanum Pen Script
- 코드·주소: IBM Plex Mono

## 리틱체는 저장소에 들어 있지 않아요

리틱체는 영상·이미지·인쇄물에 무료로 쓸 수 있지만, 글꼴 파일을 다시 배포하는 것은 금지되어 있어요.
그래서 저장소에는 올리지 않았습니다. 영상을 다시 뽑으려면 직접 받아서 이 폴더에 넣어 주세요.

1. 리틱인더스트리 공식 페이지(reaticindustry.com/reaticfont)에서 "리틱체 다운로드"
2. 압축을 풀고 `TTF/REATIC/` 안의 `REATIC-Bold.ttf`, `REATIC-NarrowBold.ttf` 두 파일을 이 폴더에 복사

파일이 없으면 Bagel Fat One 으로 대신 나옵니다.

나머지 글꼴(Bagel Fat One, Yeon Sung, Nanum Pen Script, IBM Plex Mono)은 SIL Open Font License 1.1 입니다.
