# 홍보 영상 (쇼츠·릴스, 9:16, 34초)

사이트 기본 디자인(코르크 보드)과 고민 동물 그림 그대로 만든 모션그래픽입니다. 코드로 만들어서 문구나 주소를 바꾸고 다시 뽑을 수 있어요.

## 흐름

1. 고민 쪽지가 하나씩 천천히 붙다가 점점 빨라져서 보드가 가득 참
2. 휴대폰으로 쪽지 쓰기 (학년대, 온도, 감정 우표)
3. 내 고민 동물 공개
4. 사연마다 다른 동물, "너는 뭐가 나올까"
5. 방송에서 같이 읽고 채팅으로 의견 나누기
6. 마무리

## 구성 원칙

- 시간표는 `src/timeline.json` 한 파일에 있어요. 화면과 소리가 모두 이 파일을 따릅니다.
  - `notes`: 쪽지가 붙는 시각 (간격이 점점 짧아짐)
  - `marks`: 장면 안의 주요 순간
- 박자에 화면을 끼워 맞추지 않아요. 화면이 흔들리는 강조는 다섯 군데뿐입니다 (첫 자막, 우표, 동물 공개, 물음표 카드, 마무리).
- 소리는 `scripts/make-audio.mjs` 가 직접 합성합니다 (외부 음원 없음, 저작권 걱정 없음). 장면이 바뀌는 순간에 음악이 새로 시작해요.
- 고민 동물 그림은 `public/mascots/` 에 있어요. 사이트의 `web/public/mascots/` 와 같은 파일입니다.

## 다시 뽑기

```bash
npm install
```

```bash
npm run render
```

결과: `out/shorts.mp4`

- 사이트 주소 바꾸기: `src/Root.tsx` 의 `siteUrl`
- 화면 보면서 고치기: `npm run studio`
