# 방송 후 정리하는 방법 (관리자용)

방송에서 사연을 읽으면, 사연자는 사이트에서 **"방송에서 읽혔어요"** 알림과 **다시보기 링크**(읽기 시작한 시간부터), **고민 동물**을 받아요.
손이 가는 일은 버튼 몇 번이면 끝나요.

---

## 방송 중 (방장 · 매니저 모두 가능)

1. **방송을 켜면** 관리자 페이지 → **방송** → **● 방송 시작** 을 누르세요.
   - 깜빡했다면 나중에 **시작 시각 고치기** 로 실제 시작 시각을 넣으면 돼요.
   - 방송 시작을 안 누르고 사연을 읽어도, 처음 "읽기 시작"을 누른 순간이 방송 시작으로 기록돼요. (나중에 고치면 됨)
2. **다음 사연 뽑기** → OBS 에 사연이 열려요.
3. 사연을 **읽기 시작할 때** **▶ 읽기 시작** 을 누르세요. (방송 화면이나 크게 읽기 모드 어디서든)
   - 그 시각이 기록되고 사연이 "읽음"이 돼요.
   - 방송 시작과의 차이로 다시보기 시간(예: 1시간 12분)이 자동으로 계산돼요.
4. 다 읽으면 다시 **다음 사연 뽑기**. 반복!

> "방송 예정"으로 표시해 둔 사연은 다음 사연 뽑기에서 먼저 뽑혀요. (사연 상세 → **방송 예정으로 표시**)

---

## 방송 끝난 뒤 (방장만, 5분이면 끝)

> 다시보기는 방송이 끝나고 치지직에 올라와야 생기니까, **방송 중에는 시각만 기록**해 두고 주소는 나중에 넣어요. 다음 날 해도 돼요.

1. 치지직에 다시보기가 올라오면 관리자 페이지 → **오늘 방송 정리**
   - 아직 결과를 공개하지 않은 가장 최근 방송이 자동으로 열려요. 다른 회차는 위쪽 **방송 회차** 에서 고르세요.
2. 치지직 **다시보기 주소를 한 번만** 붙여넣으세요.
   - 사연마다 읽기 시작한 시간이 붙은 링크가 자동으로 만들어져요. (아래 링크로 눌러서 확인 가능)
3. 필요하면 고치기 (안 해도 돼요)
   - **방송 시작 시각**: 고치면 모든 사연의 시간이 다시 계산돼요.
   - **사연별 다시보기 시간**: `1:12:00` 처럼 넣어요.
   - **다웅의 한마디**: 한두 줄, 비워둬도 돼요.
4. **결과 공개** → **저장하고 공개하기**
   - 오늘 읽은 사연들의 결과 카드가 한꺼번에 사연자에게 열려요.
   - 로그인한 사연자의 고민 동물은 **도감**에 모이고, 1% 확률로 **황금 동물**이 나와요.
   - 다시보기가 늦게 올라온다면 **결과를 먼저 공개**해도 돼요. 사연자 화면에는 "다시보기가 올라오면 여기에 링크가 생겨요"가 보이고, 나중에 주소를 넣고 **저장** 하면 링크가 자동으로 붙어요.

---

## 그 다음 (생각날 때)

- **상담 후기** 메뉴: 새 후기를 보고 **승인** 하면, 사연자가 공개에 동의한 후기만 첫 화면 **후기 벽**에 올라가요.
  - 욕설·저격·개인정보가 의심되는 후기는 빨간 **확인 필요** 표시가 붙어요. 승인하기 전에는 절대 후기 벽에 안 올라가요.
  - 올라간 후기도 **후기 벽에서 내리기** 로 언제든 내릴 수 있어요.
- **황금 동물** 메뉴: 사연자가 인증 코드(`GOLD-XXXX-XXXX`)와 치지직 닉네임을 남기면 여기에 떠요.
  - 코드를 확인하고 구독권을 선물한 뒤 **구독권 지급 완료** 를 누르세요.
- **그 후 이야기** 메뉴: 후속 보고나 후기가 들어온 사연만 모여 있어요. **읽기 모드로 보기** 로 "지난 사연자분들 근황" 코너를 진행하세요. (← → 방향키로 넘기기)
- 관리자 페이지 맨 위에 빨간 **확인 필요** 알림이 보이면, 후속 보고에 위험 표현이 있다는 뜻이에요.
  - 사연자에게는 상담 연락처가 이미 안내됐어요.
  - 사연을 확인한 뒤 **확인했어요** 를 누르세요.
  - 필요하면 사연 상세 → **개인 메시지** 로 짧은 메시지를 보낼 수 있어요.

---

## 자주 묻는 것

- **다시보기 링크를 눌렀는데 처음부터 나와요.** **설정 → 다시보기 링크 시간 형식** 을 다른 것으로 바꾸고 오늘 방송 정리에서 **저장** 을 한 번 더 누르세요. 사연자 화면에는 "1시간 12분부터"가 글자로도 같이 보여요.
- **실수로 읽음 처리했어요.** 사연 상세 → **방송 대기로 되돌리기**. 방송 결과도 함께 지워져요.
- **오래 못 읽은 사연은요?** 설정의 **자동 공개 기간**(기본 14일)이 지나면, 사연자에게 "아직 방송에서 못 읽었지만 사연은 잘 받았어요. 다음 방송 후보에 남아 있어요"가 보여요.
  - "확인 필요" 사연은 자동으로 안내하지 않으니 직접 확인해 주세요.
- **어제 방송을 오늘 정리해도 돼요?** 네. 아직 공개 안 한 방송이 먼저 열리고, 위쪽 **방송 회차** 에서 다른 회차도 고를 수 있어요.
- **다시보기를 기다리는 동안 다음 방송을 켜도 돼요?** 네. 지난 방송이 끝나고 몇 시간 지나면, **방송 시작** 을 누를 때 새 회차로 따로 기록돼요. (지난 방송 시작 후 8시간이 넘었고 마지막 "읽기 시작"이 3시간 넘게 지났으면 새 회차) 바로 이어서 다시 켜는 경우엔 **새 방송으로 시작** 을 누르세요.
