# 고민 동물 마스코트 만들기 지시문

지금 고민 동물은 이모지(🦝🦦🦉…)로만 나와요. 이걸 **우리 사이트에만 있는 캐릭터**로 바꾸는 지시문이에요.
**마릿수는 정하지 않아요.** 새 동물 그림을 추가할 때마다 고민 동물로 나올 수 있는 동물이 늘어나요.
그림 AI(ChatGPT 이미지, Midjourney 등)에 그대로 넣거나, 디자이너에게 외주 맡길 때 이 문서를 그대로 보내면 돼요.

> **지금 사이트에 들어간 캐릭터:** 25마리 (여우, 너구리, 햄스터, 고슴도치, 병아리, 토끼, 펭귄, 다람쥐 2종, 양, 돼지, 곰, 코알라, 판다, 고양이, 호랑이, 소, 치타, 스컹크, 비버, 카피바라, 친칠라, 물범, 고래, 우파루파).
> 관리자 화면 → **캐릭터**에서 전체 도안, 표정 9가지, 황금, 도감 빈칸 모습을 볼 수 있어요. 고민 동물은 이 캐릭터들 중에서만 나와요.
> 새 그림은 `web/public/mascots/<영문이름>.webp` 로 넣고 `supabase/functions/_shared/mascots.ts` 에 한 줄 추가하면 돼요.

## 1. 세계관 (한 줄)

> **코르크 게시판 상담소에 사는 고민 동물들.** 누가 고민 쪽지를 붙이면, 그 마음을 꼭 닮은 동물이 압정을 뽑고 쪽지 옆으로 나와요.

- 모든 동물이 **고민 쪽지(포스트잇)** 또는 **빨간 압정**을 하나씩 갖고 있어요. 이게 "우리 캐릭터"라는 공통 표시예요.
- 상담소장(대표 마스코트)은 **곰** 한 마리예요. 이름에 '다웅'을 안 넣어도, 아는 사람은 "웅 = 곰"으로 알아봐요.
  - 상담소장 곰은 고민 동물로 나오지 않고 첫 화면, 로딩, 404 화면, 방송 오버레이에만 나와요.

### 1-1. 캐릭터가 늘어나는 방법

- **고민 동물은 캐릭터 그림이 있는 동물 중에서만 나와요.** 수식어는 AI 가 사연마다 자유롭게 지어요 ("곱씹는 라쿤", "시험 끝난 판다").
- **그림은 '동물 종류'마다 한 장**이에요.
  - "곱씹는 라쿤"과 "늦잠 자는 라쿤"은 같은 라쿤 그림을 써요.
  - 수식어는 카드 글씨와 표정(기본·공감·응원·놀람 등)으로 살려요.
- **새 동물 그림을 추가하면** AI 도 그 동물을 고를 수 있게 돼요. 마릿수는 그림이 늘어나는 만큼 늘어나요.
- 새 그림이 생길 때마다 **"이번 주 새로 그려진 친구"**로 소개할 수 있어요. 방송, 릴스, 첫 화면에 계속 새 거리가 생겨요.

## 2. 모든 캐릭터 공통 디자인 규칙 (이게 제일 중요해요)

캐릭터를 하나씩 따로 만들면 그림체가 다 달라져서 "양산형"처럼 보여요. **아래 규칙을 모든 캐릭터에 똑같이** 지켜야 한 세트로 보여요.

| 항목 | 규칙 |
|---|---|
| 비율 | 2등신 (머리 : 몸 = 1 : 1), 통통하고 둥근 몸 |
| 선 | 진한 갈색 외곽선 (#2B2118), 굵기 일정, 끝이 둥근 선 |
| 채색 | 평평한 색 + 그림자 한 단계만. 그라데이션·광택·3D 없음 |
| 눈 | 작은 점 눈 또는 반달 눈. 큰 반짝이 눈(애니 눈) 금지 |
| 볼 | 연한 분홍 볼터치 동그라미 (#FFC9CF) |
| 소품 | 고민을 보여주는 소품 **딱 1개** + 공통 소품(쪽지 또는 압정) |
| 배경 | 투명 (PNG). 나중에 사이트에서 색 카드 위에 올려요 |
| 글자 | 그림 안에 글자 넣지 않기 (말풍선 글은 사이트에서 따로 넣어요) |
| 테두리 | 스티커처럼 흰 테두리 6~8px (선택. 굿즈·스티커용) |

**사이트 색 (이 안에서만 쓰기)**

- 잉크 갈색 `#2B2118` (선, 눈)
- 크림 `#FFFDF6` (밝은 면)
- 코르크 `#E2C49B` (따뜻한 갈색)
- 압정 빨강 `#E5533D` (포인트)
- 형광펜 노랑 `#FFE58A`
- 하늘 `#D6E9F5`, 분홍 쪽지 `#FFD2DC`, 연두 쪽지 `#DDF0C8`, 보라 쪽지 `#E5DAF5`

**하지 말 것**

- 카카오프렌즈, 산리오, 포켓몬, 짱구 등 **이미 있는 캐릭터를 닮게** 만들기
  - 그림 AI에 "OO 스타일로"라고 쓰지 마세요. 저작권 문제가 생겨요.
- 실제 동물 사진처럼 털을 세밀하게 그리기
- 캐릭터마다 다른 그림체, 다른 선 굵기

## 4. 한 캐릭터당 만들 그림

| 파일 | 용도 | 크기 |
|---|---|---|
| `기본` (정면, 위 표의 포즈) | 고민 동물 결과 카드, 도감 | 1024×1024 PNG 투명 |
| `표정 4종`: 기본 / 공감(눈물 글썽) / 응원(주먹 쥐기) / 놀람 | 방송 오버레이, 릴스·쇼츠 | 1024×1024 PNG 투명 |
| `황금` | 황금 고민 동물 (구독권) | 기본과 같은 포즈, 몸 전체 금색 + 반짝이 3개 |
| `실루엣` | 도감에서 아직 못 모은 칸 | 기본을 잉크 갈색 한 색으로 채운 것 |
| `스티커` | 굿즈, 디스코드·카톡 이모티콘 후보 | 흰 테두리 버전 |

파일 이름 예시: `mascot-01-parrot.png`, `mascot-01-parrot-cheer.png`, `mascot-01-parrot-gold.png`

## 5. 만드는 순서 (그림체가 안 흔들리게)

1. **상담소장 곰부터** 만들어서 그림체를 정해요. 마음에 드는 한 장이 나올 때까지 이것만 반복해요.
2. 마음에 든 곰 그림을 **참고 이미지로 넣고** 시작 멤버를 만들어요.
   - 그림 AI는 "이 그림과 같은 그림체로"가 제일 잘 먹혀요.
3. 지금까지 만든 친구들을 **한 장에 모아 보는 시트**를 만들어 그림체가 맞는지 확인해요.
   - 튀는 애가 있으면 그 애만 다시 만들어요.
4. 확정된 기본 그림으로 표정 4종 → 황금 → 실루엣 순서로 만들어요.

## 6. 그림 AI에 넣을 문장

그림 AI는 영어가 더 정확해요. 아래를 복사해서 `[ ]` 부분만 바꾸면 돼요.

### 6-1. 공통 스타일 (모든 그림 앞에 붙이기)

```
Cute original mascot character for a Korean teen worry-counseling website.
Chibi proportions (head and body equal size), round chubby body,
thick even dark-brown outline (#2B2118) with rounded line ends,
flat colors with only one soft shadow tone, no gradients, no gloss, no 3D,
small dot eyes, light pink round blush on cheeks,
limited warm palette: cream #FFFDF6, cork brown #E2C49B, pin red #E5533D, highlighter yellow #FFE58A, sky blue #D6E9F5,
the character carries a small paper sticky note or a red push pin as a signature item,
centered, full body, front view, plain transparent background, no text, no letters, no logo.
Do not resemble any existing franchise character.
```

### 6-2. 상담소장 곰 (먼저 만들기)

```
[공통 스타일]
Character: a gentle, sturdy brown bear who runs a cork-board counseling corner.
Holding a small box of red push pins in one arm and waving with the other hand,
warm closed-eye smile, a yellow sticky note stuck on its belly.
```

### 6-3. 고민 동물 (표에서 한 줄씩 바꿔 넣기)

```
[공통 스타일]
Same art style as the reference image (the bear).
Character: [동물 영어 이름] — "[한국어 이름]".
Personality: [성격 영어로].
Prop: [고민 소품 영어로].
Pose and expression: [표정·포즈 영어로].
Main color: [대표색].
```

시작 멤버 영어 칸 예시 (그대로 써도 돼요. 새 동물은 같은 형식으로 한 줄 추가)

### 6-4. 표정·황금·실루엣 만들 때 덧붙이기

- 표정: `Same character, same pose, expression changed to [teary and empathetic / cheering with a raised fist / surprised with open mouth].`
- 황금: `Same character and pose, entire body recolored in warm metallic gold with three small sparkles, outline stays dark brown.`
- 실루엣: `Same character and pose, filled completely with a single flat color #2B2118, no details.`

### 6-5. 모아 보기 시트 (새 친구 추가할 때마다)

```
[공통 스타일]
Character lineup sheet: [N] different animal mascots in the same art style, arranged in a neat grid,
each with its prop: [동물 이름 나열]. Consistent line weight and proportions across all characters.
```

## 7. 사이트에 들어가는 곳 (그림이 준비되면)

- **고민 동물 결과 카드**: 이모지 자리에 캐릭터 그림
  - AI 는 그림이 있는 동물 중에서만 골라요. 수식어만 자유롭게 지어요.
- **도감**: 칸 수가 정해져 있지 않고, 사이트에 그림이 생긴 동물만큼 늘어나요.
  - 못 모은 동물은 실루엣, 모으면 그림, 황금은 금색 테두리.
  - "지금까지 그려진 친구 23마리 중 7마리"처럼 보여서, 새 친구가 생길 때마다 다시 들어올 이유가 돼요.
- **방송 오버레이**: 사연 읽을 때 그 동물의 `공감` 표정, 결과 공개 때 `응원` 표정
- **첫 화면·로딩·404**: 상담소장 곰
- **릴스·쇼츠**: "새로 그려진 친구" 시리즈. 새 동물이 생길 때마다 한 편씩, 끝없이 이어져요.

## 8. 맡기기 전에 확인할 것

- **AI로 만들 때**: 쓰는 그림 AI의 상업적 이용 조건을 확인해요. 굿즈·후원 상품에 쓸 거면 특히요.
- **디자이너에게 맡길 때**: 계약서에 아래를 꼭 넣어요.
