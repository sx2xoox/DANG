# 시리즈 쇼츠 (인스타 릴스 · 유튜브 쇼츠, 9:16)

이틀에 한 편씩 올리는 짧은 영상이에요. 형식을 돌아가며 써서 매번 다른 느낌이 나요.
기존 홍보 영상(`video/`)은 건드리지 않고, 글꼴과 고민 동물 그림만 같이 써요.

## 형식

| 형식 | 파일 | 내용 | 노리는 것 |
|---|---|---|---|
| 고민 동물 도감 (`dex`) | `src/formats/Dex.tsx` | "○○한 사람 특징" 3가지 → 그런 너의 고민 동물 공개 | 저장·공유, 25마리라 시리즈로 오래 감 |
| 너라면? 투표 (`poll`) | `src/formats/Poll.tsx` | 상황 하나 → A vs B → 댓글로 골라줘 | 댓글 |
| 이런 적 있으면 너도 (`check`) | `src/formats/Check.tsx` | 체크리스트 5줄 → 3개 이상이면 이 동물 | 공유, "나야 나" 댓글 |
| 다웅의 편지 (`letter`) | `src/formats/Letter.tsx` | 다웅이 지친 사람에게 쓰는 짧은 편지 | 저장, 팔로우 |

나중에 넣을 것: 방송 하이라이트 (유튜브 생방송 녹화본으로), 실제 사연 소개 (쇼츠 사용에 동의한 사연만, 이름 빼고).

모든 편의 첫 화면은 제목과 그림이 다 나와 있어서 그대로 썸네일이 돼요. 마지막 2.5초는 사이트로 오게 하는 안내예요. 전체 길이는 10~12초로 짧게 (끝까지 보고 다시 도는 비율이 높을수록 노출이 잘 돼요).

## 편 추가하기

`src/episodes.ts` 목록에 한 편을 추가해요. (id 는 `s08`, `s09`… 순서대로)

- `props`: 영상에 들어갈 글
- `post`: 올릴 때 쓰는 제목·설명·해시태그

## 뽑기

```bash
npm install
```

```bash
npm run render
```

고른 편만 뽑을 때:

```bash
npm run render -- s08
```

결과 (`out/편이름/`):

- `video.mp4`: 올릴 영상
- `cover.jpg`: 썸네일 (인스타 커버로 올림. 프로필 격자에서 잘려도 다 보이게 가운데에 모아 둠. 도감·체크리스트는 정답 동물을 실루엣으로 가림)
- `post.txt`: 제목·설명·해시태그·추적 주소

화면 보면서 고치기: `npm run studio`

## 올리기

1. 인스타 릴스·유튜브 쇼츠에 `video.mp4` 를 올려요.
2. 음악은 각 앱에서 골라요. (앱 안의 음악은 저작권 걱정이 없고, 유행하는 음악이 노출에도 좋아요)
3. 설명은 `post.txt` 를 복사해서 붙여요.
4. 유입 세기
   - 유튜브: 설명란에 추적 주소(`사이트주소/v/s01`)를 넣어요.
   - 인스타: 올린 날 프로필 링크를 그 편의 추적 주소로 바꿔 두면 따로 세어져요.
   - 관리자 → 통계에서 편마다 몇 명이 들어왔고 사연을 몇 개 보냈는지 보여요. 잘 되는 형식을 더 자주 돌리면 돼요.
