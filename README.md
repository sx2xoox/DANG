# 다웅 고민 사연함

치지직 스트리머 **다웅**의 생방송 고민 상담 코너용 사연 접수 사이트예요.
시청자가 휴대폰이나 PC로 사연을 보내면, 방장은 관리자 페이지에서 사연을 골라 방송에서 읽고, 시청자는 나중에 답장과 함께 AI 가 지어준 **고민 동물** 카드를 받아요.

👉 **설치와 운영 방법은 [docs/설치-안내.md](docs/설치-안내.md) 를 보세요.**

## 주요 기능

- **사연 보내기**: 로그인 없이 / 로그인해서. 한 화면에 한 단계씩(10단계), PC 는 넓은 카드와 키보드 진행(Enter, Tab, 방향키). 쓰는 중 자동 임시 저장.
- **접수증**: 접수번호 + 비밀 코드, 복사·이미지 저장(보관용/공유용), 고민 동물은 물음표로 가려 두었다가 답장과 함께 공개.
- **답장 카드**: 카드가 뒤집히며 고민 동물 공개, 다웅의 답장, 방송 날짜·다시보기·채팅 판결.
- **내 사연함**: 사연 목록과 상태, 답장 도착 빨간 점, 고민 동물 도감, 변신 기록, 후속 보고, 삭제·탈퇴.
- **관리자 페이지 `/admin`**: 비밀번호(서버에서 확인, 해시 저장, 5회 실패 시 10분 잠금), 매니저 코드, 목록/상세, 읽기 모드, AI 답장 초안, 답장 대기, 룰렛 뽑기, OBS 카드 조종, 통계, 설정(디자인 프리셋, 접수 멈춤, 자동 답장), CSV.
- **OBS 카드 `/obs?key=...`**: 1920×1080 투명 배경, 룰렛 장면과 고민 동물 공개 연출, 본문은 절대 표시하지 않음.
- **디자인 프리셋 3종**: 기본(남색), 코르크 보드, 캡슐 뽑기 — 관리자 설정에서 바꿈.
- **안전**: 연락처 경고, 자해·학대 표현 감지 시 상담 연락처 안내 + "확인 필요" 표시(자동 답장 제외), AI 전송 전 개인정보 가리기, 도배 방지.

## 구조

```
web/                         사이트 (React + Vite, Cloudflare Pages 에 배포)
supabase/migrations/         DB 표 + 접근 규칙(RLS) + 자동 답장 예약 작업
supabase/functions/public    시청자용 서버 함수 (제출, 답장 확인, 사연 옮기기)
supabase/functions/admin     관리자용 서버 함수 (비밀번호 확인, 관리, AI)
supabase/functions/obs       OBS 카드용 서버 함수
supabase/functions/_shared   화면과 서버가 같이 쓰는 설정(사연함 단계, 안전 검사, 기본 동물 16종)
docs/설치-안내.md             설치·운영 안내 (한국어)
```
