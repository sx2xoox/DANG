# 다웅 고민 사연함

치지직 스트리머 **다웅**의 생방송 고민 상담 코너용 사연 접수 사이트예요.
시청자가 휴대폰이나 PC로 사연을 보내면 그 자리에서 AI 가 사연을 읽고 **고민 동물** 결과(MBTI 결과처럼)를 보여줘요.
다웅은 관리자 페이지에서 사연을 검토·승인하고, 방송 중 OBS 로 사연을 열어 읽으며 시청자와 이야기해요.

👉 **설치와 운영 방법은 [docs/설치-안내.md](docs/설치-안내.md) 를 보세요.**

## 주요 기능

- **사연 보내기**: 로그인 없이 / 로그인해서. 한 화면에 한 단계씩(10단계), PC 는 넓은 카드와 키보드 진행(Enter, Tab, 방향키). 쓰는 중 자동 임시 저장.
- **고민 동물 결과**: 제출 직후 카드가 뒤집히며 공개, 왜 이 동물인지, 코멘트, 그 동물의 한마디, 해시태그, 고민 성분표. 카드 이미지 저장·공유.
- **사연 조회 코드**: 접수번호 + 비밀 코드로 결과와 진행 상황(검토 중 / 방송 대기 / 방송에서 읽음) 확인, 사연 삭제.
- **내 사연함**: 사연 목록과 진행 상황, 고민 동물 도감, 변신 기록, 후속 보고, 삭제·탈퇴.
- **관리자 페이지 `/admin`**: 비밀번호(서버에서 확인, 해시 저장, 5회 실패 시 10분 잠금), 매니저 코드, 검토 대기(승인/반려), 방송 화면(대기열, 다음 사연 뽑기, OBS 조작), 사연함, 통계, 설정(디자인 프리셋, 접수 멈춤), CSV.
- **OBS 화면 `/obs?key=...`**: 1920×1080 투명 배경, 승인된 사연 본문을 크게 열어 보여줌, 본문 넘기기, 같은 날 사연끼리 룰렛, 고민 동물 공개 연출.
- **디자인 프리셋 3종**: 기본(남색), 코르크 보드, 캡슐 뽑기 — 관리자 설정에서 바꿈.
- **안전**: 연락처 경고, 자해·학대 표현 감지 시 상담 연락처 안내 + "확인 필요" 표시, AI 전송 전 개인정보 가리기, 도배 방지.

## 구조

```
web/                         사이트 (React + Vite, Cloudflare Pages 에 배포)
supabase/migrations/         DB 표 + 접근 규칙(RLS)
supabase/functions/public    시청자용 서버 함수 (제출 + 고민 동물, 사연 조회, 사연 옮기기)
supabase/functions/admin     관리자용 서버 함수 (비밀번호 확인, 관리, AI)
supabase/functions/obs       OBS 카드용 서버 함수
supabase/functions/_shared   화면과 서버가 같이 쓰는 설정(사연함 단계, 안전 검사, 기본 동물 16종)
docs/설치-안내.md             설치·운영 안내 (한국어)
```
